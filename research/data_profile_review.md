## Decision

Exhaustive sparse similarity against roughly ten million targets for each of 1.73 million test queries is a serious feasibility risk. Keep the TF-IDF implementation as a reference, and screen an independently implemented lexical inverted index before expensive training or inference.

`colab_screen.json` indexes every training target using deterministic name, address, character, and number/token keys. Country prefixes are enabled only after auditing all labelled pairs. Keys exceeding 2,048 postings are omitted, not sampled; this loses retrieval evidence and must be evaluated. The query returns a union of up to 20 candidates from each of three evidence views. Index construction uses 32 separately compacted buckets and restart checkpoints. Numeric postings use internal SQLite row IDs; public candidates are resolved back to original entity IDs.

A record emits at most 24 postings. Before compaction, ten million targets can therefore require roughly 3 GB of raw posting data, plus the normalized database and output arrays. This is a bound on raw postings, not a total storage estimate or free-tier guarantee. Redundant identical Latin text is stored once and transparently restored on reading. Query indexes cover S1 rows only. Actual index bytes and runtime are reported by the benchmark.

The continuation notebook deliberately stops after the audit and full-target benchmark. A 256-query fitting sample is an initial feasibility screen, not a final accuracy evaluation. Expand that sample and assess country recall before promotion. If viable, fit E003 on 5,000 fitting queries, tune on 1,000 separate queries, and evaluate 1,000 development queries. E004 provides optional OOF stage-two stacking under the same retrieval settings. Neither method is promoted; holdout and full inference have not run on the real dataset. France transfer remains unverified.

Full inference may require substantial candidate/feature storage; the benchmark estimates numeric feature bytes before that decision. Do not infer that sharded storage alone makes a full submission cheap.
